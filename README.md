# Agenda da lavanderia

Uma agenda para consultar pelo celular possíveis horários para lavar, secar ou fazer os dois ciclos em sequência.

**[Abrir a agenda](https://melrs.github.io/notthateasy/)**

Escolha o dia e toque em uma faixa para ver os horários. Horários indicados precisam ser confirmados no aplicativo oficial. A agenda é somente para consulta e não faz reservas.
